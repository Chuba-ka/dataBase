# Сервис аренды автомобилей — лабораторные работы №1 и №2

ЛР2 выполнена на исходной модели ЛР1. [Документация ЛР2: запуск, реализация, CTE и результаты проверки](docs/LAB2.md).
Все новые сценарии находятся в `sql/`; общий запуск — `sql/run.sql`.

Вариант 9. PostgreSQL. Шесть таблиц: офисы, категории автомобилей, клиенты,
сотрудники, автомобили и аренды.

## Файлы

- `sql/create.sql` — создание пользователя и базы.
- `sql/schema.sql` — таблицы и ограничения.
- `sql/data.sql` — тестовые данные.
- `sql/constraints_test.sql` — девять некорректных INSERT/UPDATE.
- `sql/migration.sql` — заготовка для отдельного требования преподавателя;
- `docs/БД ЛР 1 2026.pdf` — требования лабораторной.
- [ER-диаграмма (SVG)](docs/ER_diagram.svg) — изображение шести таблиц и связей.

## Запуск

Если сервер PostgreSQL остановлен, запустить локальный кластер 

```bash
sudo pg_ctlcluster 18 main start
pg_isready
```

При повторном запуске с уже созданными таблицами и данными достаточно запустить
сервер и подключиться; повторно выполнять `create.sql`, `schema.sql` и `data.sql` не нужно:

```bash
psql -U car_rental_user -d car_rental -h localhost
```

Создать пользователя и базу один раз:

```bash
sudo -u postgres psql -v ON_ERROR_STOP=1 -f sql/create.sql
```

Создать таблицы и заполнить их:

```bash
psql -U car_rental_user -d car_rental -h localhost -f sql/schema.sql
psql -U car_rental_user -d car_rental -h localhost -f sql/data.sql
```

Скрипты рассчитаны на пустую базу. Примеры используют идентификаторы,
полученные при первом заполнении. Изменение schema.sql не обновляет
уже существующие таблицы.

Проверить ограничения:

```bash
psql -U car_rental_user -d car_rental -h localhost -f sql/constraints_test.sql
```

Ожидается девять сообщений `ERROR`: повторный паспорт, несовершеннолетний
клиент, неправильные даты, неизвестный клиент, пересечение аренд,
отрицательная стоимость, неправильный возврат, завершение без возврата
и отсутствие обязательной марки автомобиля. Каждый тест выполняется
в отдельной транзакции с откатом. Ошибки намеренные: оценивайте сообщения,
а не только код завершения psql.

## Принятые правила

- Период аренды не включает день возврата: следующая аренда может начаться
  в этот же день. Аренда на ноль дней не допускается.
- Отменённая аренда сохраняется в истории, но не блокирует автомобиль.
- Стоимость обязательна и неотрицательна. Это сумма договора, которая
  не пересчитывается автоматически при изменении тарифа категории.
- Только завершённая аренда имеет фактическую дату возврата.
  Возврат допускается раньше или позже плановой даты, но не раньше начала.
- Статус машины описывает возможность эксплуатации: `available`,
  `maintenance`, `retired`. Занятость на даты определяется арендой;
  отдельного статуса `rented` нет.
- Автоматическая проверка технического статуса машины при оформлении
  аренды и перевод в `overdue` по времени не реализованы.
- Год выпуска ограничен диапазоном 2000–2100, VIN — длиной 17 символов.
- Связанные записи защищены от удаления через `ON DELETE RESTRICT`.
